Keahlian Utama

Berbagai layanan dan kompetensi teknis yang saya kuasai.

Networking & Router

Konfigurasi Mikrotik (Firewall, DHCP, Access Point), manajemen bandwidth, serta analisis keamanan lalu lintas jaringan tingkat lanjut.

Instalasi Sistem CCTV

Pemasangan IP Camera & Analog, penarikan kabel LAN/Coaxial rapi, crimping, serta konfigurasi monitoring online.

Hardware & Maintenance

Analisis kerusakan, perbaikan komponen, pembersihan berkala, dan perakitan perangkat PC maupun laptop secara presisi dan aman.

Data & System Recovery

Pemulihan file data dari RAW drive atau bad sector menggunakan perangkat lunak khusus, serta perbaikan sistem operasi (OS).

Memperbaiki Printer

Troubleshooting dan perbaikan berbagai jenis printer, mencakup hardware mekanik maupun error software.

Pengalaman Kerja

Rekam jejak dan implementasi langsung di lapangan.

Instalasi CCTV Perkantoran

Pemasangan sistem CCTV multi-titik di area perkantoran dengan penataan kabel terstruktur (menggunakan pipa conduit & cable tray rapi). Konfigurasi NVR, IP statis, dan integrasi pemantauan jarak jauh via smartphone & laptop.

Instalasi CCTV Kapal Laut

Pemasangan kamera CCTV standar pelayaran (weatherproof/anti-korosi) di armada kapal. Penarikan kabel aman dan terlindung dari cuaca laut ekstrem, serta setup ruang kendali terpusat di anjungan untuk pengawasan ruang mesin.

Keamanan Jaringan Layer 7

Mengatur dan menerapkan aturan firewall ketat serta pemblokiran protokol Layer 7 pada Mikrotik Router untuk mencegah akses jaringan lokal dari trafik tidak diinginkan.

Pemulihan Penyimpanan (Deep Recovery)

Berhasil memulihkan file database penting dari penyimpanan eksternal yang mengalami kerusakan sistem file secara menyeluruh tanpa data loss.
